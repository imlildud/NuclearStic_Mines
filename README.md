## About

<img width="477" height="242" alt="features" src="assets/hud/features.png" />

Nuclear-Stic Mines is a **turn-based tactical roguelike** that blends classic Minesweeper mechanics with procedural exploration, character abilities, and rescue missions.

Navigate through hazardous zones, flag hidden dangers, rescue lost children, and bring them back to safety. Each decision matters — one wrong step could be your last.

---

## How to Play

<img width="200" height="200" alt="legacy" src="assets/hud/menu/legacy.png" />

| Action | Control |
|--------|---------|
| Move | `WASD` or touch pad |
| Place / Remove Flag | `Arrow Keys` or touch pad |
| Pause | `ESC` |
| Rescue | Step on a child, then return to start |

**Objective:** Rescue all children marked as wanted and deliver them to the start tile (house).

---

## Game Modes

<img width="477" height="242" alt="gamemodes" src="assets/hud/gamemodes.png" />

| Mode | Description |
|------|-------------|
| **Legacy** | Progressive difficulty. Each victory advances to a higher level. Tracks your record. |
| **Hardcore** | Extreme version of Legacy. No health regen, limited flag regen, forced Ash zone, and permadeath. |
| **Daily** | Same seeded mission for all players. One attempt per day. |
| **Custom** | Full control over size, hazards, obstacles, goals, zone, and seed. |

## Key Mechanics

<img width="200" height="200" alt="options" src="assets/hud/menu/options.png" />

| Mechanic | Description |
|----------|-------------|
| **Vision** | Only tiles within your vision range are visible. Mountains block line of sight. |
| **Height** | Cannot climb more than 1 level up. Falling 2+ levels deals damage (if enabled). |
| **Hazards** | Mines (lethal), Cactus / Deadbush (damage), Radioactive (area damage). |
| **Obstacles** | Natural (blocked), Pit (lethal), River (pushes you downstream). |
| **Flags** | Mark suspected hazards. Chef converts flags into points. |

## Scoring

| Action | Points |
|--------|--------|
| Rescue a child | +500 |
| Mark a hazard | +200 |
| Complete a level | Difficulty bonus |
| Failed flag | -200 |
| Take damage | -100 |

Grades range from **S** (100%+) to **F** (below 50%).
