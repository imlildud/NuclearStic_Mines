A **turn-based tactical game** where you:

- ◆ **Explore** a procedurally generated board
- ◆ **Flag** hidden mines (just like Minesweeper)
- ◆ **Rescue** children and bring them to the start
- ◆ **Survive** hazards, obstacles, and enemies

## How to play

1. **Move** with `WASD`
2. **Place flags** with `Arrow Keys`
3. **Or use the virtual pad**
4. **Rescue children** → take them to the **start tile** (house)
5. **Win** when all children are rescued

## Key mechanics

| Mechanic | How it works |
|----------|---------------|
| **Vision** | You only see tiles around you. Mountains block vision. |
| **Height** | Can't climb more than 1 level up/down. |
| **Hazards** | Mines (lethal), Cactus (damage), Radioactive (area damage) |
| **Obstacles** | Natural (blocked), Pit (lethal), River (pushes you) |
