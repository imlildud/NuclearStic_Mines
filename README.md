# Nuclearstic Mines

> Un roguelike inspirado en Minesweeper y Ajedrez.  
> Sobrevive, rescata y presume tu puntuación en cada partida.

---

## Descripción
Nuclearstic Mines es un juego roguelike donde controlas personajes con habilidades únicas para rescatar objetivos y sobrevivir en tableros generados proceduralmente. Cada partida es única, y si pierdes, pierdes; no hay guardados, solo una fria muerte.

---

## Modos de juego

- **Desafío diario**: Tablero fijo cada día, diseñado para poner a prueba tu estrategia.  
- **Modo libre**: Selecciona nivel de dificultad para entrenar.
